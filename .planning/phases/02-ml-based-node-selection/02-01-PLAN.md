  <name>Create feature extraction utilities</name>
  <files>algorithms/ml_features.py</files>
  <action>
Create ml_features.py with feature extraction function:

1. Define FEATURE_KEYS list matching research recommendations:
   - degree (total degree)
   - out_degree
   - in_degree
   - clustering_coefficient (local connectivity)
   - avg_neighbor_degree (average degree of neighbors)

2. Implement extract_node_features(graph, node, positions=None):
   - Compute out_degree = graph.out_degree(node)
   - Compute in_degree = graph.in_degree(node)
   - Get neighbors from graph.adj_list.get(node, [])
   - Compute clustering coefficient using existing helper or implement:
     * triangles = count of triangles involving node
     * possible = degree * (degree - 1) / 2
     * clustering = triangles / possible if possible > 0 else 0
   - Compute avg_neighbor_degree = mean([graph.out_degree(n) + graph.in_degree(n) for n in neighbors]) or 0
   - If positions provided: add spatial_x, spatial_y from positions[node]

3. Return dict with all feature keys and float values

DO NOT use expensive centrality features (betweenness, closeness) - they are O(nm) or O(n²).
Use only O(1) features for scalability (degree, clustering, neighbors).
  </action>

Create ml_node_selector.py with MLNodeSelector class:

1. Import: NodeSelector from node_selection.py, MLPOrderer from learned_ch_orderer.py, extract_node_features from ml_features.py

2. class MLNodeSelector(NodeSelector):
   - __init__(self, graph, model_path=None):
     * Call super().__init__(graph)
     * Set self.model = None
     * If model_path provided: try loading MLPOrderer.load(model_path), catch FileNotFoundError/JSONDecodeError, print warning if fails

   - ml_score(self, node) -> float:
     * If self.model is None: return self.degree(node)  # Fallback
     * Extract features using extract_node_features(self.graph, node)
     * Build feature_vector in order of self.model.feature_keys
     * Return self.model.score(features)

   - select_top_k(self, k) -> Set[int]:
     * Override parent method
     * Use ml_score if model available, else degree
     * Use heapq.nlargest(k, range(self.graph.nodes), key=scoring_fn)
     * Return set(top_k_nodes)

   - select_top_k_percent(self, percentage) -> Set[int]:
     * Override parent method
     * Compute k = max(1, int(self.graph.nodes * percentage))
     * Call self.select_top_k(k) and return result

MATCH existing MLPOrderer pattern from learned_ch_orderer.py:
- model.score(features) returns float
- features is Dict[str, float]
- model.feature_keys provides expected feature order

DO NOT modify node_selection.py - extend via inheritance only.
