3. Define train_mlp() function (MATCH learned_ch_train.py pattern):
   - Signature: train_mlp(x, y, hidden=16, epochs=10, lr=0.005)
   - Initialize weights: w1, b1, w2, b2 using np.random.default_rng(42)
   - Training loop with stochastic gradient descent
   - Forward: h = relu(x @ w1 + b1), pred = h @ w2 + b2
   - Backward: compute gradients with gradient clipping (-1.0, 1.0)
   - Return: w1, b1, w2, b2

4. Define generate_training_data():
   - Generate 3-4 graph types: grid, scale_free, geometric, road_like
   - For each graph:
     * Sample nodes (random 100-200 nodes per graph)
     * For each node: extract features using extract_node_features()
     * Simulate contraction benefit as proxy label:
       - Use degree-based heuristic: benefit = degree / max_degree (normalized 0-1)
       - OR use simple metric: benefit = degree - avg_neighbor_degree
   - Collect ~5000-10000 total samples across graph types
   - Return: X (np.ndarray features), y (np.ndarray labels)

5. main() function:
   - Set random seeds (random.seed(42), np.random.seed(42))
   - Generate training data: X, y = generate_training_data()
   - Filter infinite values: finite_mask = np.isfinite(X).all(axis=1) & np.isfinite(y)
   - Normalize: mean = X.mean(axis=0), std = X.std(axis=0) + 1e-6
   - Normalize X: X_norm = (X - mean) / std
   - Normalize y: y_mean, y_std, y_norm = (y - y_mean) / y_std
   - Train: w1, b1, w2, b2 = train_mlp(X_norm, y_norm, hidden=16, epochs=10, lr=0.005)
   - Create model dict: {
       "feature_keys": FEATURE_KEYS,
       "mean": mean.tolist(),
       "std": std.tolist(),
       "y_mean": float(y_mean),
       "y_std": float(y_std),
       "w1": w1.tolist(),
       "b1": b1.tolist(),
       "w2": w2.tolist(),
       "b2": b2.tolist()
     }
   - Save to models/ml_node_selector.json (create directory if needed)
   - Print metrics: samples, features, epochs, final MSE estimate

6. if __name__ == "__main__": main()
