Create validate_ml_node_selector.py with baseline comparison:

1. Imports:
   - sys, os
   - numpy as np
   - from algorithms.ml_node_selector import MLNodeSelector
   - from algorithms.node_selection import DegreeSelector
   - from algorithms.graph_gen import GraphGenerator

2. Define compare_selection_methods(graph, model_path, k_percent=0.1):
   - Instantiate MLNodeSelector(graph, model_path=model_path)
   - Instantiate DegreeSelector(graph)
   - Get k = max(1, int(graph.nodes * k_percent))
   - Select nodes using ML: ml_nodes = ml_selector.select_top_k(k)
   - Select nodes using degree: degree_nodes = degree_selector.select_top_k(k)
   - Compare node quality metrics:
     * Average degree of selected nodes (higher is better)
     * Average clustering coefficient of selected nodes
     * Jaccard similarity between ML and degree selections (measures difference)
   - Return dict with metrics for both methods

3. Define validate_on_graph(graph_type, graph_params, model_path):
   - Generate test graph based on type and params
   - Run comparison: metrics = compare_selection_methods(graph, model_path)
   - Print results showing:
     * Graph type and size
     * Average degree (ML vs degree baseline)
     * Jaccard similarity (0 = completely different, 1 = identical)
     * Improvement percentage if ML outperforms on degree metric
   - Return metrics

4. main() function:
   - Check model_path = "models/ml_node_selector.json" exists
   - If missing: print error and exit
   - Test on multiple graph types:
     * Grid: 10x10 (100 nodes)
     * Scale-free: 200 nodes, m=2
     * Geometric: 150 nodes, radius=0.2
   - For each graph type: call validate_on_graph()
   - Print summary:
     * Number of graph types tested
     * Average improvement across graphs
     * Final verdict: "ML improves over baseline" or "Baseline performs similarly"
   - Return success if ML shows improvement on at least 2/3 graph types

5. if __name__ == "__main__": main()

KEY VALIDATION: ML selection should differ from degree selection (Jaccard < 0.8) and show higher average degree on selected nodes.
